# 麻酔管理料計算アプリ

[![Live Demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-blue)](https://ysuzuki1978.github.io/anesthesia_calc/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Version](https://img.shields.io/badge/Version-1.2-green)](https://github.com/ysuzuki1978/anesthesia_calc)

iOS版から移植された麻酔管理料計算アプリのWebバージョンです。保険点数の計算ロジックを正確に移植した、完全スタンドアロンのWebアプリです。

## すぐに使う

**GitHub Pages**: [**アプリを開く**](https://ysuzuki1978.github.io/anesthesia_calc/)

**ローカル**: `index.html` をダブルクリック → ブラウザで開く → すぐに利用可能

## 特徴

- **計算ロジックの正確な移植**: Swift版の複雑な計算ロジック（借用ロジック方式）を完全移植
- **完全スタンドアロン**: `index.html` 1ファイルだけで動作、サーバー不要
- **即座に利用可能**: 依存関係なし、インストール不要
- **レスポンシブデザイン**: デスクトップ・モバイル・タブレット対応

## 機能

### 計算ロジック
- 麻酔レベル別基本点数（困難患者・通常患者）
- 時間延長加算（借用ロジック方式）
- 硬膜外麻酔加算・時間延長加算
- 神経ブロック加算
- 時間外・深夜休日加算

### UI機能
- リアルタイム計算
- 詳細内訳表示
- 入力値検証
- レスポンシブデザイン

| 4      | 9,015点     | 6,500点     |
| 5      | 8,300点     | 6,000点     |

### 時間延長加算（30分単位）
| レベル | 加算点数 |
|--------|---------|
| 1      | 1,800点 |
| 2      | 1,200点 |
| 3      | 900点   |
| 4      | 650点   |
| 5      | 600点   |

> レベル4（腹腔鏡を用いた手術等が行われる場合に相当する区分）は、名称変更を伴う一連の見直しの一部として、基本点数（イ 9,130→9,015点／ロ 6,610→6,500点）と時間延長加算（660→650点）が調整されました。それ以外のレベル・加算・倍率は変更ありません。

### 硬膜外麻酔加算
| 部位      | 基本加算 | 時間延長加算（30分単位） |
|-----------|---------|---------------------|
| 頸・胸部  | 750点   | 375点               |
| 腰部      | 400点   | 200点               |
| 仙骨部    | 170点   | 85点                |

### 神経ブロック加算
- 硬膜外代用: 450点
- その他: 45点

### 時間外・深夜休日加算
- 時間外加算: 1.4倍
- 深夜・休日加算: 1.8倍

## 借用ロジック方式について

元のSwift版で実装されている複雑な時間延長計算方式を正確に移植:

1. 基本時間（120分）を高いレベルから順に消費
2. 延長時間は30分ブロック単位で計算
3. 不足分は下位レベルから借用
4. 各レベルの加算点数で計算

## アプリの更新通知機能

このアプリはGitHub Pagesで配信される静的サイトのため、ユーザーのブラウザに古いキャッシュが残ったまま使われ続けることがあります。それを防ぐため、`index.html` は同一オリジンの `version.json` を以下のタイミングで取得し、バージョンが異なる場合は画面上部に更新バナーを表示します。

- ページ読み込み時（読み込み後1.5秒）
- タブがバックグラウンドから再度アクティブになった時
- 開きっぱなしのタブ向けに10分毎

**リリース時の手順**: 点数表やロジックを変更したら、`index.html` 内の `APP_VERSION` 定数と `version.json` の `version` を同じ値に更新してからデプロイしてください。両者が一致していれば通知は表示されません。
